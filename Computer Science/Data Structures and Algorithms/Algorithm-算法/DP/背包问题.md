# 01背包

题目

> 有一个背包容量为m，还有n件物品，每件物品只有一个，它们的重量分别是w1、w2、……、wn，它们的价值分别是v1、v2、……、vn。求最大总价值。

## 二维数组

思路：dp

1. 确定状态表示

```C++
dp[i][j] // 背包容量为j时，从下标为0到i的物品里任意取的最大价值
// 最大总价值为dp[n][m]
```

2. 确定边界和遍历顺序

```C++
// 边界：i = 0 或 j = 0时，dp[i][j] = 0
// 遍历顺序：外 i 内 j ，从小到大
```

3. 找到状态转移方程

```C++
// 1.放不下，继承上一层状态
dp[i][j] = dp[i - 1][j]
// 2.放得下，放入物品
dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - wi] + vi)
```

### 核心代码

```C++
for (int i = 1; i <= n; i++)
{
	for (int j = 1; j <= m; j++)
	{
		if (j < w[i]) // 放不下
			dp[i][j] = dp[i - 1][j];
		else // 放得下
			dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i]);
	}
}
// 时间：O(nm)
// 空间：O(nm)
```

## 一维滚动数组

思路：dp

1. 确定状态表示

```C++
dp[j] // 背包容量为j时，从下标为0到i的物品里任意取的最大价值
// 最大总价值为dp[m]
```

2. 确定边界和遍历顺序

```C++
// 边界：i = 0 时，dp[j] = 0
// 遍历顺序：外 i 内 j ，i 从小到大，j 从大到小
```

3. 找到状态转移方程

```C++
// 放得下，放入物品
dp[j] = max(dp[j], dp[j - wi] + vi)
```

### 核心代码

```C++
// 新增一层物品i的状态来源于上一层的状态
for (int i = 1; i <= n; i++)
	for (int j = m; j >= w[i]; j--) // 从大到小进行更新
		dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
// 时间：O(nm)
// 空间：O(n)
```

# 完全背包

题目

> 有一个背包容量为m，还有n件物品，**每件物品有无限个**，它们的重量分别是w1、w2、……、wn，它们的价值分别是v1、v2、……、vn。求最大总价值。

## 二维数组

思路：dp

1. 确定状态表示

```C++
dp[i][j] // 背包容量为j时，从下标为0到i的物品里任意取的最大价值
// 最大总价值为dp[n][m]
```

1. 确定边界和遍历顺序

边界：i = 0 或 j = 0时，dp[i][j] = 0

遍历顺序：外 i 内 j ，从小到大

1. 找到状态转移方程

```C++
// 继承上一层状态
dp[i][j] = dp[i - 1][j];
// 1.放不下，继承当前层状态
dp[i][j] = dp[i][j]
// 2.放得下，放入物品
dp[i][j] = max(dp[i][j], dp[i][j - wi] + vi)
```

### 核心代码

```C++
for (int i = 1; i <= n; i++)
{
	for (int j = 1; j <= m; j++)
	{
		dp[i][j] = dp[i - 1][j]; // 继承上一层状态
		if (j >= w[i]) // 放得下
			dp[i][j] = max(dp[i][j], dp[i][j - w[i]] + v[i]);
	}
}
// 时间：O(nm)
// 空间：O(nm)
```

遍历顺序：外 i 内 j ，从小到大

1. 找到状态转移方程

for (int i = 1; i <= n; i++)

# 多重背包

题目

> 有一个背包容量为m，还有n件物品，**每件物品有ci个**，它们的重量分别是w1、w2、……、wn，它们的价值分别是v1、v2、……、vn。求最大总价值。

## 转换成01背包

思路：将每件物品平铺成ci个物品，最终使每个物品都只有1个。

时间：O(n*m*k)
