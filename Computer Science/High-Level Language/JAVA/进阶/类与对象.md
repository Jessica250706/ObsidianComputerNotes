# 类

## 定义

### 语法

```Java
public class 类名{

}
```

### 举例

```Java
public class Person{
    // 变量
    public String name; // 姓名
    public int age; // 年龄

    // 方法：访问修饰符  返回值类型  方法名([参数列表])
    public void sleep(){
        System.out.println("sleep");
    }
    public void eat(){
        System.out.println("eat");
    }
}
```

# 类与对象的关系

## 解释说明

### 类

是描述多个事物的共有特征和行为的一个抽象体。

### 对象

是一个具体的事物，每一个属性和每一个行为都是具体的。类是对象的集合体。类是用来构建具体的对象的。

## 语法

```Java
类名 对象名 = new 类名(); // 类
对象名.属性名 = 属性值; // 对象
```

## 举例

```Java
// 这里p称为对象名，跟数组名一样，本质都是变量。只是在面向对象中称之为对象名
Person p = new Person();
p.age = 21;
p.name = "Jessica";
```

## 结论

类是对多个事物的抽象描述，描述的是他们的共同特征和行为举止。但需要注意的是：**类中描述的共同特征，在对象创建出来之后是跟随对象走的。行为举止也是一样，属于对象。**

# 成员变量和成员方法

## 成员变量

### 解释说明

在类中定义的变量就是成员变量。成员变量顾名思义是属于成员（具体的对象、具体的事物）的，成员变量有初始值，见下表。

|成员变量的类型|初始值|
|---|---|
|引用数据类型|NULL|
|整数|0|
|浮点数|0.0|
|boolean|false|
|char|'\u0000’|

### 访问成员变量的语法

```Java
对象名.属性名;
```

### 局部变量

- 解释说明
    - 局部变量就是在方法内部定义的变量。局部变量没有初始值，因此，局部变量在使用之前必须完成初始化操作。当局部变量与成员变量同名时，**局部变量的优先级更高**。
- 特别的，
    - 局部变量的作用范围更小，就在局部变量所定义的方法内，因此局部变量在方法内的优先级要高于成员变量

### this关键字

若局部变量与成员变量同名，可用this关键字表示当前对象（使用new创建出来的对象）。

```Java
this.成员变量
this.成员方法
```

## 成员方法

### 解释说明

在类中定义的方法就是成员方法。成员方法顾名思义是属于成员（具体的对象、具体的事物）的。

### 调用成员方法的语法

```Java
// []中内容可有可无
对象名.方法名([参数列表]);
```

# 构造方法

## 概念

构造方法是一种特殊的方法，主要用于创建对象以及完成对象的属性初始化操作。构造方法不能被对象调用。

## 语法

```Java
// []中内容可有可无
访问修饰符 类名([参数列表]){
    
}
```

## 举例

```Java
public class Person{
    // 变量
    public String name; // 姓名
    public int age; // 年龄

    // 方法：访问修饰符  返回值类型  方法名([参数列表])
    public void sleep(){
        System.out.println("sleep");
    }
    public void eat(){
        System.out.println("eat");
    }

    // 构造方法
    public Person(String name, int age){
        this.name = name;
        this.age = age;
    }
}
```
