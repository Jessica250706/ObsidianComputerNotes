# 概念

是编程语言中的一种常见的数据结构，能够存储一组相同类型的数据。

# 作用

存储一组相同类型的数据，方便进行数理统计（求最大值、最小值、平均值以及总和），也可以进行信息的展示。

# 定义

## 一维数组

### 语法

```Java
数据类型[] 数组名;
数组名 = new 数据类型[数组的长度];
数组名 = new 数据类型[]{元素1, 元素2, ..., 元素n};

数据类型[] 数组名 = new 数据类型[数组的长度];

数据类型[] 数组名 = {元素1, 元素2, ..., 元素n};
```

### 内存模型

![[image 14.png|image 14.png]]

### 举例

```Java
public final class Main {
    public static void main(String[] args) {
        // 1.数组的定义：数据类型[] 数组名;
        // 1.1
        String[] names; // 存储多个名字
        names = new String[10];
        // 1.2
        String[] names2;
        names2 = new String[]{"John", "Jessica"};

        // 2.数据类型[] 数组名 = new 数据类型[数组的长度];
        int[] numbers = new int[10];

        // 3.数据类型[] 数组名 = {元素1, 元素2, ..., 元素n};
        double[] scores = {99.9, 15.2, 45.7};

        // 4.数组的定义： 数据类型[] 数组名 = new 数据类型[]{元素1,元素2, ....};
        long[] times = new long[]{1500, 4568, 15671};
    }
}
```

## 二维数组

### 语法

```Java
数据类型[][] 数组名 = new 数据类型[数组的长度][数组的长度];
```

### 举例

```Java
public final class Main {
    public static void main(String[] args) {
        // 定义了一个长度为8的二维数组，每一个空间中只能存放长度为2的字符串数组
        String[][] personNames = new String[8][2];
        personNames[0] = new String[]{"Jessica", "Fang"};
    }
}
```

# 基本要素

## 标识符

也是**数组的名称**，只是在数组中的一个专业术语，本质就是一个变量名。

## 数组元素

也就是数组中的每一块空间存储的数据。

## 元素类型

也就是数组存放的数据类型。

## 元素下标

数组中每一个元素所处的位置就是数组元素的下标，数组元素下标从 0 开始，因此，数组元素下标的最大值为数组长度 - 1。

# 特征

数组的长度一旦定义就不能发生改变，除非给数组重新赋值，才能改变数组的大小。

# 元素赋值

## 语法

```Java
数组名[元素下标] = 元素值;
```

## 增加

无法直接增加，需要新建一个数组。

```Java
public final class Main {
    public static void main(String[] args) {
        String[] personArr = {"A", "B", "C"};
        String[] newArr = new String[personArr.length + 1];
        int indexF = 1; // F的位置
        for (int i = 0; i < indexF; i++) {
            newArr[i] = personArr[i];
        }
        newArr[indexF] = "F";
        for (int i = indexF; i < personArr.length; i++) {
            newArr[i + 1] = personArr[i];
        }
        personArr = newArr;
        // 输出
        for (int i = 0; i < personArr.length; i++) {
            System.out.println(personArr[i]);
        }
    }
}
```

## 删除

无法直接删除，需要新建一个数组。

```Java
public final class Main {
    public static void main(String[] args) {
        String[] personArr = {"A", "F", "B", "C"};
        String[] newArr = new String[personArr.length - 1];
        int index = 1; // 删除的下标
        for (int i = 0; i < index; i++) {
            newArr[i] = personArr[i];
        }
        for (int i = index; i < newArr.length; i++) {
            newArr[i] = personArr[i + 1];
        }
        personArr = newArr;
        for (int i = 0; i < personArr.length; i++) {
            System.out.println(personArr[i]);
        }
    }
}
```

## 拷贝

### 语法

```Java
System.arrayCopy(原数组, 拷贝的开始位置, 目标数组, 存放的开始位置, 拷贝的元素个数);
```

### 举例

```Java
public final class Main {
    public static void main(String[] args) {
        String[] personArr = {"A", "B", "C"};
        String[] newArr = new String[personArr.length + 1];
        int indexF = 1;
        // 第一次拷贝
        System.arraycopy(personArr, 0, newArr, 0, indexF);
        newArr[indexF] = "F";
        // 第二次拷贝
        System.arraycopy(personArr, indexF, newArr, indexF + 1, personArr.length - indexF);
        personArr = newArr;
        for (int i = 0; i < personArr.length; i++) {
            System.out.println(personArr[i]);
        }
    }
}
```

## 扩容

### 语法

```Java
数据类型[] 标识符 = Arrays.copyOf(原数组, 新数组的长度);
```

### 作用

新建一个数组，并将原数组的所有元素全部拷贝至新数组中

### 举例

```Java
public final class Main {
    public static void main(String[] args) {
        String[] personArr = {"A", "B", "C"};
        String[] newArr = Arrays.copyOf(personArr, personArr.length + 1);
        newArr[newArr.length - 1] = "F";
        personArr = newArr;
        for (int i = 0; i < personArr.length; i++) {
            System.out.println(personArr[i]);
        }
    }
}
```
