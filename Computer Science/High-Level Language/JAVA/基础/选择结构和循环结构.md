# 选择结构

## if 选择结构

### 语法

```Java
if(条件1) // 若条件1成立，则运行括号里的代码
{
    // 代码块1
}
else if(条件2) // 若条件1不成立，但条件2成立
{
    // 代码块2
}
else // 若条件1和条件2都不成立
{
    // 代码块3
}
```

p.s.可嵌套。

## Switch 选择结构

### 语法

```C++
switch(表达式) // 作用在表达式的结果上
{
    case 常量1: // 若表达式的结果为常量1，表示开关被打开，执行代码块1
        // 代码块1
        break; // 表示开关已经做完事情，跳出switch
    case 常量2:
		    // 代码块2
        break;
    case 常量3:
		    // 代码块3
        break;
    default: // 若表达式的结果不是常量1、常量2和常量3，表示开关被打开，执行代码块4
		    // 代码块4
        break;
}
```

### 支持的数据类型

```C++
基本数据类型：byte short int char 
引用数据类型：string 
枚举：Enum
```

p.s. switch 选择结构从**JDK1.7 开始**才支持 String 类型

# 循环结构

## while 循环结构

### 循环三要素

1. 定义循环变量并赋初值
2. 循环条件
3. 循环变量的更新

### 语法

```Java
// 定义循环变量并赋初值
while (循环条件) // 循环条件
{
	// 更新循环变量
}
```

## do-while 循环结构

### 区别

先执行，再判断条件

### 语法

```Java
do {

} while(循环条件);
```

## for 循环

### 语法

```Java
for (定义循环变量并赋初值; 循环条件; 循环变量的更新)
{

}
```

# 流程控制

## break 关键字

### 应用场景

只能应用于 while 循环、do-while 循环、for 循环和 switch 选择结构

### 作用

1. 应用在循环结构中时，表示终止 break 所在的循环，执行循环结构下面的代码，通常与 if 选择结构配合使用
2. 应用在 switch 选择结构时，表示终止 break 所在的 switch 选择结构

## continue 关键字

### 应用场景

只能应用在循环结构中（while 循环、do-while 循环和 for 循环）

### 作用

表示跳过本次循环，进入下一次循环，通常与 if 选择结构配合使用

# 多重循环

## 二重循环

### 举例

```Java
while(外层循环条件){
	//外层循环操作
	while(内层循环条件){
		//内层循环操作
	}
	//外层循环操作
}
while(外层循环条件){
	//外层循环操作
	for(循环变量初始化; 内层循环条件; 循环变量更新){
	 //内层循环操作
	}
	//外层循环操作
}
```

# 标号

## 标签 label

### 语法

```Java
标号名称: 循环结构
```

### 作用

给代码添加一个标记，方便后面使用。通常应用在循环结构中，与 break 语句配合使用。

### 举例

```Java
public final class Main {
    public static void main(String[] args) {
        Scanner sc  = new Scanner(System.in);
        while(true) {
            System.out.println("1.学生成绩管理");
            System.out.println("请选择序号：");
            int menuNum = sc.nextInt();
            if (menuNum == 1) {
                childMenu: while(true) {
                    System.out.println("1.添加成绩");
                    System.out.println("2.返回主菜单");
                    System.out.println("请选择菜单编号：");
                    int number = sc.nextInt();
                    switch (number) {
                        case 1:
                            System.out.println("选择添加成绩");
                            break;
                        case 2:
                            System.out.println("选择返回主菜单");
                            break childMenu; // JAVA中的标号，即一个代码的标记
                    }
                }
            }
        }
    }
}
```
