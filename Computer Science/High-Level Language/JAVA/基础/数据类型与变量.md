## 转换

在 JAVA 中，数值类型相互兼容，在进行运算时，必须保证表达式中的参与运算的所有数据类型保持一致。

### 自动类型转换

定义：相互兼容的多种数据类型在运算时，**小转大**即为自动类型转换。

Eg. **10** + 0.5 ⇒ **10.0** + 0.5 = 10.5

### 强制类型转化

定义：相互兼容的多种数据类型在运算时，**大转小**即为强制类型转换。

规则：

```Java
(目标数据类型)变量名
```

Eg. 68.5 + 1.5 ⇒ (int)**70.0** ⇒ **70**

# 变量

### 定义

定义：一个内存空间地址的表示

内存：栈内存 + 堆内存

### 声明

```Java
// 第一种
数据类型 变量名;
变量名 = 变量值;

// 第二种
数据类型 变量名 = 变量值;
```

p.s.在 JAVA 中，变量名是**唯一**的。

p.ss.变量在使用之前，必须经过**初始化**操作，即赋值。

```Java
// 让计算机在栈上开辟一块1个字节大小的空间，并将这块空间命名为b，然后将整数1放入开辟好的空间b中
byte b = 1;

// 让计算机在栈上开辟一块2个字节大小的空间，并将这块空间命名为s，然后将整数5放入开辟好的空间s中
short s = 5;

// 让计算机在栈上开辟一块4个字节大小的空间，并将这块空间命名为a，然后将整数10放入开辟好的空间a中
int a = 10;

// 让计算机在栈上开辟一块8个字节大小的空间，并将这块空间命名为t，然后将整数3放入开辟好的空间t中
long t = 3;

// 让计算机在栈上开辟一块4个字节大小的空间，并将这块空间命名为f，然后将浮点数3.0放入开辟好的空间f中
// 在JAVA中，浮点数默认是双精度浮点数，故需在数字后加上f/F，使表示为单精度浮点数
float f = 3.0f; // float f = 3.0F;

// 让计算机在栈上开辟一块8个字节大小的空间，并将这块空间命名为d，然后将浮点数23.0放入开辟好的空间d中
double d = 23.0;

// 在JAVA中的布尔类型变量，编译完成后就不存在了。因为JAVA是在C++基础上进行开发，而在C++中使用0与非0表示flase和true。
// 而JVM是执行JAVA程序的场所，在JVM规范中有明确说明，单个boolean类型的变量，在编译的过程中会被翻译成int类型的变量，此时占用4个字节的空间。
// 对于boolean类型的数组，在翻译的过程中会被翻译成byte类型的数组，此时每个变量占用1个字节的空间
boolean flag = true;

// 让计算机在栈上开辟一块2个字节大小的空间，并将这块空间命名为sex，然后将汉字男放入开辟好的空间sex中
// char类型变量能存储汉字。因为JAVA采用Unicode编码，Unicode编码中收录的汉字占用的是2个字节，同时char类型变量也占用2个字节。若在Unicode编码中未收录的汉字则不一定能使用char类型变量存储。
char sex = '男';
```

### 命名规则

1. 变量名只能以**字母**、**下划线**和**$**开始，其余部分由任意多的字母、数字、下划线和$ 组成。（严格区分大小写）
2. 变量名**不能**是 JAVA 中的**保留字（关键字）**。

### 命名规范

在 JAVA 中，变量名采用**驼峰命名法**，即变量名组成的第一个单词的首字母小写，其余单词首字母均大写。
