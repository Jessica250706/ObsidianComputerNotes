# 逻辑短路

## 逻辑与短路

使用逻辑与连接的多个条件中，只要其中一个条件为**假**，那么该条件后的所有条件将得不到执行，从而形成**逻辑与短路**。

## 逻辑或短路

使用逻辑或连接的多个条件中，只要其中一个条件为**真**，那么该条件后的所有条件将得不到执行，从而形成**逻辑或短路**。
