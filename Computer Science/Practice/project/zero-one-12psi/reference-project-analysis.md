# 3.自定义表格相关

## 3.1.封装组件

```
NodTree：树形选择器组件，封装了 Element UI 的 el-tree 并提供更友好的交互体验。
StockDetail：点击详情打开，是库存详情弹窗组件，用于展示特定商品的库存流水记录。
PageStatus：页面状态统计组件，用于动态显示数据的汇总信息。
```
